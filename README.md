### 🚀 How to Use
1. **[Download](https://github.com/egortrpv/orionmediadownloader/releases/latest)** the `.exe` file.
2. **Run** the application.
3. **Paste** a media link.
4. Select quality and click **Download**.

### ✨ Supported Sources & Formats
* **Platforms**: YouTube, TikTok, Instagram, VK, X and 1,000+ other supported websites.
* **Media**: Videos, audio tracks, and photos.
